Build a simple sliding tile puzzle web app called "Shuffle".

 

Requirements:

- Single file: Site/index.html with inline CSS and plain JavaScript. No frameworks, no build step.

- Show the title "Shuffle" at the top of the page.

- 3x3 grid with tiles numbered 1-8 and one empty space.

- Clicking a tile that is directly next to the empty space slides it into the empty space.

- A "Shuffle" button that randomly reorders the tiles (use a simple random sort of the tile array).

- A move counter and a timer that starts on the first move.

- After the board is rendered, check whether the tiles are in order (1-8, empty last) and show a "You solved it!" message when they are.

- The board starts in solved order when the page loads.

- Clean, centered layout with square tiles and a clear look for the empty space.

 

Keep the code short and readable. One function per responsibility (render, move, shuffle, checkWin). Add brief comments.
